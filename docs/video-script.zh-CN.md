# 75–90 秒插件介绍脚本

作者：**BenzWood**。展示镜头使用实际运行结果；烘焙和引擎画面先由作者验收，再录制对应段落。

标题建议：**Blockbench 梯形像素总是歪？这个插件还能烘焙带进游戏**

| 时间 | 画面 | 口播 |
| --- | --- | --- |
| 0–8 秒 | 梯形腿、矩形 UV，同一角度放大原来的折弯。 | “UV 明明排成了长方形，梯形上的像素却在中间拐弯。这个问题我终于处理了。” |
| 8–18 秒 | 切换修复预览两次，观察真实色块与格线。 | “这是我做的四边形 UV 修复插件。让四条边按相同比例分格，像素随着面宽平顺变化。” |
| 18–28 秒 | 展示原工程顶点、面数与矩形 UV。 | “编辑时不用细分模型，也不用重新排 UV。贴图预览、像素格线和画笔定位一起修正。” |
| 28–40 秒 | 从文件加载 JS；选中面，工具菜单启用。 | “下载一个 JS 文件，从插件页面加载。选中 Mesh 或具体的面，点工具里的启用修复，就能继续画。” |
| 40–50 秒 | 一像素画笔在旧对角线附近落笔；吸管取色。 | “原图继续用原分辨率编辑，支持取消、撤销，也能随时对比原效果。” |
| 50–65 秒 | 点文件菜单原来的模型导出，展示自动倍率和 1/16、1/32 精度。 | “想带进游戏，直接按原流程导出模型。插件自动烘焙，从一倍开始，逐级选够用的倍率，输出补偿贴图和模型副本。共享 UV 冲突也会自动分开，原工程保留。” |
| 65–78 秒 | 展示直接保存的模型与伴随贴图，再展示实际 Unity 或 Godot 画面。 | “副本固定原来的三角化，不加位置顶点，用普通材质就能显示烘焙效果。像素贴图用最近邻采样；有限分辨率会有近似误差，按实际镜头验收。” |
| 78–90 秒 | GitHub 作者、MIT、下载与 Issues。 | “我是 BenzWood，插件按 MIT 开源。当前还是早期版本，主要处理有效凸四边形和静态贴图。链接放在简介，欢迎反馈。” |

最后一段在仓库已公开后使用。引擎镜头未验收时，改为展示模型副本普通预览，口播“再从副本按原流程导出，游戏效果需要核对”。不要宣称全球首创、任何模型都有效或烘焙像素绝对一致。

简介草稿：

> 四边形 UV 修复 / Quad UV Fix，作者 BenzWood，MIT 开源。修复梯形 Mesh 搭配矩形 UV 的像素折弯，同步预览、格线与绘画定位。0.3.0 提供自动最小整数倍率烘焙：输出游戏用模型副本和补偿 PNG，增加 1/16、1/32 精度和可选边缘抗锯齿，原生 glTF/GLB、FBX、OBJ 完整导出自动烘焙；共享 UV 冲突在副本中自动分配补偿区域，普通材质使用，不要求引擎专用 Shader。烘焙是有限分辨率近似，详见兼容性说明。基于 Blockbench 5.2.1，早期版本。下载与反馈：https://github.com/BenzWood/blockbench-quad-uv-fix
